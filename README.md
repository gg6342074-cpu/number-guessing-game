# Игра «Угадай число»

Небольшая консольная игра на Python. Программа случайно загадывает целое число от 0 до 100, а игрок пытается его угадать.

## Как играть

1. Запустите программу.
2. Введите целое число от 0 до 100.
3. Следуйте подсказкам:
   - если загаданное число меньше вашей догадки, программа попросит ввести число меньше;
   - если оно больше — попросит ввести число больше.
4. Игра завершится, когда вы угадаете число.

## Запуск

Убедитесь, что Python установлен, затем запустите в терминале:

```bash
python main.py
